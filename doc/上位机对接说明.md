# map_manager_3d 上位机接口

上位机只调 **6 个 ROS 服务**，**只给地图名字**（如 `map01`）。

## 启动（一次性，常驻）

```bash
source /opt/ros/humble/setup.bash
ros2 launch map_manager_3d map_manager_3d.launch.py
```

## 服务一览

| 服务 | 类型 | 用途 |
|---|---|---|
| `/map_manager_3d/set_mode` | `map_manager_3d/srv/SetMode` | 切模式：`mapping` / `localization` / `idle` |
| `/map_manager_3d/save_map` | `map_manager_3d/srv/SaveMap` | 存图（建图态调用） |
| `/map_manager_3d/switch_map` | `map_manager_3d/srv/SwitchMap` | 换图定位 |
| `/map_manager_3d/list_maps` | `map_manager_3d/srv/ListMaps` | 列地图（下拉框） |
| `/map_manager_3d/get_current_map` | `map_manager_3d/srv/GetCurrentMap` | 查当前地图 |
| `/map_manager_3d/delete_map` | `map_manager_3d/srv/DeleteMap` | 删除地图 |

---

## 1. set_mode

**请求**

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `mode` | string | — | `"mapping"` / `"localization"` / `"idle"` |
| `map_name` | string | `""` | 仅 `localization` 用：切到该图定位 |
| `x` `y` `theta` | float64 | 0 | 可选初始位姿，**非 0 才生效**，theta 单位**度** |

**响应**

| 字段 | 类型 | 说明 |
|---|---|---|
| `success` | bool | 模式**确实就绪**才为 true |
| `mode_ready` | bool | 同上（idle 恒 false） |
| `message` | string | 中文说明，失败原因直接展示给用户 |
| `mode` | string | 实际生效的模式 |
| `config_file` | string | 生成的 yaml 路径 |
| `command` | string | 等价的手动启动命令 |

| mode | 做什么 | success=true 判据 |
|---|---|---|
| `mapping` | 停定位 → 起建图 | `/lightning/save_map` 可用 |
| `localization` | 停建图 → 起定位（用 `map_name` 指定的图） | 定位已发话题 |
| `idle` | 建图、定位都停掉 | 两者都已停 |

```bash
ros2 service call /map_manager_3d/set_mode map_manager_3d/srv/SetMode "{mode: 'mapping'}"
ros2 service call /map_manager_3d/set_mode map_manager_3d/srv/SetMode "{mode: 'localization', map_name: 'map01'}"
ros2 service call /map_manager_3d/set_mode map_manager_3d/srv/SetMode "{mode: 'idle'}"
```

> 建图与定位互斥：`mapping` 会先停定位，`localization` 会先停建图。上位机**不需要**自己启停任何进程。

## 2. save_map（仅建图态）

**请求**：`map_name` string、`overwrite` bool（默认 true）

**响应**：`success` bool、`message` string、`map_name`、`map_dir`、`map_path`、
`files` string[]、`bytes_total` uint64、`lightning_response` uint32、`index_fixed` bool

```bash
ros2 service call /map_manager_3d/save_map map_manager_3d/srv/SaveMap "{map_name: 'map01'}"
```

- 只判断 `success`；失败时 `message` 里会给原因（覆盖失败会自动回滚旧图，不会毁图）。

## 3. switch_map（换图定位）

**请求**：`map_name` string、`x` `y` `theta` float64、`restart` bool（默认 true）

**响应**：`success`、`message`、`map_name`、`map_dir`、`map_path`、`config_file`、
`restarted` bool、`startup_verified` bool、`files` string[]

```bash
ros2 service call /map_manager_3d/switch_map map_manager_3d/srv/SwitchMap "{map_name: 'map01'}"
```

- `startup_verified=true` → 定位已出话题，可以开始导航任务。

## 4. list_maps

**请求**：`only_valid` bool（默认 false，true = 只返回可用的图）

**响应**：`success`、`message`、`maps_root` string、`current_map` string、
`running_mode` string（`"mapping"`/`"localization"`/`""`）、`maps` `MapInfo[]`

`MapInfo` 字段（完整定义见 `msg/MapInfo.msg`）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | string | 地图名（下拉框显示 + 其它服务入参） |
| `valid` | bool | **推荐用它判断能否使用** |
| `locatable` / `nav_ready` | bool | 能定位 / 能导航 |
| `missing` / `warnings` | string[] | 缺失件 / 告警，可直接显示 |
| `is_current` | bool | 是否当前图 |
| `chunk_ok_count` / `chunk_count` | uint32 | 分块完整性（如 2/2） |
| `bytes_total` | uint64 | 体积（字节） |
| `mtime` | float64 | 最后修改时间（unix 秒） |
| `map_path` | string | 地图目录（带尾斜杠） |
| `start_pose` | float64[7] | 建图起点位姿 x y z qx qy qz qw |
| `dir` / `index_txt` / `global_pcd` / `map_yaml` / `map_pgm` | string | 各文件全路径 |
| `has_index` / `has_chunks` / `has_global_pcd` / `has_map_yaml` / `has_map_pgm` / `has_keyframes` | bool | 单件存在性 |
| `missing_chunks` | string[] | 缺失的分块 |
| `dyn_pcd_count` | uint32 | 动态图层文件数 |
| `layout` | string | `"dir"`（标准）/ `"path"` |
| `yaml_image` / `yaml_image_exists` | string / bool | 栅格 yaml 里的 image 字段 |

## 5. get_current_map

**响应**：`success`、`message`、`current_map` string、`map_dir`、`map_path`、
`running_mode` string、`running_detected` bool、`valid` bool

```bash
ros2 service call /map_manager_3d/get_current_map map_manager_3d/srv/GetCurrentMap "{}"
```

## 6. delete_map

**请求**：`map_name` string、`force` bool（默认 false；删当前图必须 true）

**响应**：`success`、`message`、`map_name`、`map_dir`、`bytes_freed` uint64、`deleted_files` string[]

---

## 话题

| 话题 | 类型 | 说明 |
|---|---|---|
| `/map_manager_3d/current_map` | `std_msgs/String` | 当前地图名，latched，订阅即得当前值 |

## 最简调用顺序

```
建图：set_mode{mapping} →（遥控走车）→ save_map{名字} → set_mode{idle} 或 set_mode{localization, 名字}
换图：list_maps → switch_map{名字}
```

## 三条注意

1. `save_map` 必须在建图态（`set_mode{mapping}` 之后）调用；
2. 所有调用是**同步**的，请给足超时（`save_map` 可能几分钟）；不要并发调用这几个服务；
3. 任何失败把响应里的 `message` 直接显示给用户即可（中文、含原因）。

# 附：详细例子

## 例 1：列地图（下拉框）

```bash
$ ros2 service call /map_manager_3d/list_maps map_manager_3d/srv/ListMaps "{only_valid: false}"

response:
map_manager_3d.srv.ListMaps_Response(
  success=True,
  message='共 1 张地图（/home/h/ddh/code/test/lidar-slam_ws/data）',
  maps_root='/home/h/ddh/code/test/lidar-slam_ws/data',
  current_map='',
  running_mode='',
  maps=[
    map_manager_3d.msg.MapInfo(
      name='map01',
      dir='/home/h/ddh/code/test/lidar-slam_ws/data/map01',
      map_path='/home/h/ddh/code/test/lidar-slam_ws/data/map01/',
      layout='dir',
      index_txt='/home/h/ddh/code/test/lidar-slam_ws/data/map01/index.txt',
      global_pcd='/home/h/ddh/code/test/lidar-slam_ws/data/map01/global.pcd',
      map_yaml='/home/h/ddh/code/test/lidar-slam_ws/data/map01/map.yaml',
      map_pgm='/home/h/ddh/code/test/lidar-slam_ws/data/map01/map.pgm',
      has_index=True, has_chunks=True,
      chunk_count=2, chunk_ok_count=2, missing_chunks=[],
      has_global_pcd=True, has_map_yaml=True, has_map_pgm=True, has_keyframes=True,
      dyn_pcd_count=0,
      locatable=True, nav_ready=True, valid=True,
      missing=[], warnings=[],
      yaml_image='map.pgm', yaml_image_exists=True,
      start_pose=[-0.06648111, -0.23241268, -0.00199178,
                  0.00506666, -0.01212413, 0.00502875, 0.99990102],
      is_current=False,
      bytes_total=27304088,
      mtime=1790211796.562682)])
```

**上位机怎么用**：`maps` 逐条填下拉框（显示 `name`，可附 `bytes_total`/`mtime`）；
只允许选择 `valid=true` 的；`is_current=true` 的那条打勾；选完拿 `name` 去调 `switch_map`。

## 例 2：查当前地图（没在跑时会这样说）

```bash
$ ros2 service call /map_manager_3d/get_current_map map_manager_3d/srv/GetCurrentMap "{}"

response:
map_manager_3d.srv.GetCurrentMap_Response(
  success=True,
  message='尚未设置当前地图（state_file=.../data/.current_map），也没有运行中的 lightning 进程',
  current_map='', map_dir='', map_path='',
  running_mode='', running_detected=False, valid=False)
```

定位跑起来以后再问，就会是（实测）：

```
current_map='map01', running_mode='localization', running_detected=True, valid=True
message='当前地图: map01（来自运行中进程，valid=True）'
```

## 例 3：开始建图

```bash
$ ros2 service call /map_manager_3d/set_mode map_manager_3d/srv/SetMode "{mode: 'mapping'}"

response:
map_manager_3d.srv.SetMode_Response(
  success=True,
  message='已生成建图配置 .../data/.generated/slam.yaml（system.map_root_path=.../data/）；
           已启动: ros2 launch lightning slam_online.launch.py config:=.../slam.yaml
           （日志 .../data/.generated/logs/slam_1790215465142808302.log）；
           启动校验: /lightning/save_map 已可用（建图态就绪）；
           存图落点与定位读取天然一致（system.map_root_path=.../data）',
  mode='mapping',
  config_file='.../data/.generated/slam.yaml',
  command='ros2 launch lightning slam_online.launch.py config:=.../slam.yaml',
  mode_ready=True)
```

**上位机怎么用**：`success=true` → 界面进入"建图中"，允许遥控；`false` → 显示 `message`。
定位若本来在跑，这次调用会把定位停掉再起建图（不需要上位机干预）。

## 例 4：存图

**正常成功**（真机建出图后调用，字段形如）：

```bash
$ ros2 service call /map_manager_3d/save_map map_manager_3d/srv/SaveMap "{map_name: 'map01'}"

response:
map_manager_3d.srv.SaveMap_Response(
  success=True,
  message='地图 map01 已保存到 .../data/map01（定位件 2 个分块，26.0 MB）；
           旧图已备份到 .../data/.backup/map01_1790xxxx（确认新图没问题后自行删除）',
  map_name='map01',
  map_dir='.../data/map01',
  map_path='.../data/map01/',
  files=['.../data/map01/index.txt', '.../data/map01/map.yaml',
         '.../data/map01/map.pgm', '.../data/map01/global.pcd', '0.pcd', '1.pcd'],
  bytes_total=27304088,
  lightning_response=0,
  index_fixed=False)
```

**失败 + 自动回滚**（实测：空会话存图，lightning 直接挂掉）：

```bash
$ ros2 service call /map_manager_3d/save_map map_manager_3d/srv/SaveMap "{map_name: 'map01'}"

response:
map_manager_3d.srv.SaveMap_Response(
  success=False,
  message='调用 /lightning/save_map 失败: 服务 /lightning/save_map 超时(20s)；
           已回滚旧图到 .../data/map01（修正 0 条分块路径）',
  map_name='map01', map_dir='', map_path='', files=[],
  bytes_total=0, lightning_response=0, index_fixed=False)
```

**上位机怎么用**：只看 `success`。失败时 `message` 里若出现 `已回滚旧图` → 说明旧图完好，
可以提示用户"存图失败，请确认已建出地图后重试"。

## 例 5：换图定位

```bash
$ ros2 service call /map_manager_3d/switch_map map_manager_3d/srv/SwitchMap "{map_name: 'map01'}"

response:
map_manager_3d.srv.SwitchMap_Response(
  success=True,
  message='换图 map01 完成（map_path=.../data/map01/）；
           已生成定位配置 .../data/.generated/loc_map01.yaml（system.map_path=.../data/map01/）；
           此前没有运行中的定位，已按要求启动: 已启动: ros2 launch lightning loc_online.launch.py
             config:=.../loc_map01.yaml（日志 .../logs/loc_1790215499683901073.log）；
           启动校验: 已发现 /chassis/lidar_odom 或 /localization/map 的发布者',
  map_name='map01',
  map_dir='.../data/map01',
  map_path='.../data/map01/',
  config_file='.../data/.generated/loc_map01.yaml',
  restarted=True,
  startup_verified=True,
  files=['.../data/map01/index.txt', '.../data/map01/map.yaml',
         '.../data/map01/map.pgm', '.../data/map01/global.pcd'])
```

**上位机怎么用**：`success && startup_verified` → 可以开始导航任务；
定位本来在跑时会自动重启，本来没跑会自动启动；建图若在跑会先被停掉。

**带初始位姿的小例子**（车没停在建图起点时）：

```bash
$ ros2 service call /map_manager_3d/switch_map map_manager_3d/srv/SwitchMap \
    "{map_name: 'map01', x: 5.0, y: 1.0, theta: 0.0}"
# theta 单位是"度"；全 0 表示用地图原点（= 建图起点）
```

**只生成配置、不动进程**（上位机自己管进程时）：

```bash
$ ros2 service call /map_manager_3d/switch_map map_manager_3d/srv/SwitchMap \
    "{map_name: 'map01', restart: false}"
# response: success=True, restarted=False, startup_verified=False, config_file='.../loc_map01.yaml'
# 自己执行： ros2 launch lightning loc_online.launch.py config:=<config_file>
```

## 例 7：删除地图（三种情况）

```bash
# ① 成功
$ ros2 service call /map_manager_3d/delete_map map_manager_3d/srv/DeleteMap "{map_name: 'docdemo'}"
response:
map_manager_3d.srv.DeleteMap_Response(
  success=True,
  message='已删除地图 docdemo（.../data/docdemo，释放 0.0 MB）',
  map_name='docdemo', map_dir='.../data/docdemo',
  bytes_freed=0, deleted_files=['.../data/docdemo'])

# ② 删的是当前图且没带 force → 被拒（保护）
$ ros2 service call /map_manager_3d/delete_map map_manager_3d/srv/DeleteMap "{map_name: 'map01'}"
response:
map_manager_3d.srv.DeleteMap_Response(
  success=False,
  message='map01 是当前使用中的地图，拒绝删除；确实要删请传 force=true',
  map_name='map01', map_dir='.../data/map01', bytes_freed=0, deleted_files=[])

# ③ 图不存在
$ ros2 service call /map_manager_3d/delete_map map_manager_3d/srv/DeleteMap "{map_name: 'nosuchmap'}"
response:
map_manager_3d.srv.DeleteMap_Response(
  success=False,
  message='地图 nosuchmap 不存在（.../data/nosuchmap）',
  map_name='nosuchmap', map_dir='.../data/nosuchmap', bytes_freed=0, deleted_files=[])
```

**上位机怎么用**：删除前建议先 `list_maps` 确认存在；要删当前图就在界面上加二次确认，然后传 `force=true`。

## 例 8：两个端到端流程（命令序列 + 每步看什么）

**A. 新建一张图，并立刻用它定位**

```bash
# 1) 进建图态（会自动停掉定位、起建图）
ros2 service call /map_manager_3d/set_mode map_manager_3d/srv/SetMode "{mode: 'mapping'}"
#    看 success / mode_ready → true 才能让车动

# 2) 遥控车走一圈（本包不参与）；RViz 订阅 /lio/global_map 确认已建出点云

# 3) 存图（用新名字，不覆盖任何已有图）
ros2 service call /map_manager_3d/save_map map_manager_3d/srv/SaveMap "{map_name: 'map02'}"
#    看 success（true = 已落盘并校验通过）

# 4) 立刻用它定位（会自动停掉建图、起定位）
ros2 service call /map_manager_3d/set_mode map_manager_3d/srv/SetMode \
  "{mode: 'localization', map_name: 'map02'}"
#    看 success / mode_ready

# 5) 确认定位在输出
ros2 topic hz /chassis/lidar_odom
```

**B. 换场地：切到已有的图**

```bash
ros2 service call /map_manager_3d/list_maps map_manager_3d/srv/ListMaps "{only_valid: true}"   # 选一张
ros2 service call /map_manager_3d/switch_map map_manager_3d/srv/SwitchMap "{map_name: 'map01'}"
#    success=true && startup_verified=true → 可以开始导航任务
```
